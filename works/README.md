# 작업 기록

주 단위(ISO 주차, 월요일 시작)로 `works/<연도>/W<주차>.md`(한 일)와 `W<주차>_TODO.md`(할 일)를 둔다. 주차는 `date +%V`, 연도는 `date +%G`(ISO 주차의 연도. 예: 2027-01-01은 `2026/W53`).

## 한 일 — `W41.md`

- 맨 위에 `# W41 (2026-10-05 ~ 10-11)`, 이어서 날짜별 섹션(`## 2026-10-10`)에 그날 한 일을 적는다.

## 할 일 — `W41_TODO.md`

- 우선순위별 섹션에 체크박스로 적는다. 끝난 항목은 지우지 않고 `[x]`로 체크한다.
- 지금 생각하는 남은 일일 뿐, 언제든 추가·삭제·순서 변경할 수 있다. 끝난 항목만 `[x]`로 남기고, 필요 없어진 항목은 지운다.

## 새 주가 시작되면

1. `W42.md`, `W42_TODO.md`를 만든다.
2. `W41_TODO.md`에서 끝나지 않은 `[ ]` 항목을 섹션 구조 그대로 `W42_TODO.md`로 옮긴다.
3. `W42.md` 맨 위에 `이전 주: W41.md`를 적는다.
4. 지난주 파일은 더 고치지 않는다.

## 쓰는 법

- 결정과 이유를 우선 남긴다. "무엇을 했다"는 git에도 남지만, "왜 이렇게 정했다", "해 봤는데 안 됐다"는 여기에만 남는다.
- 기록은 쓴 시점의 사실이다. 코드와 다르면 코드가 맞고, 중요한 내용은 코드에서 다시 확인한다.

## 그 밖

형식 설명은 `docs/`, 산출물 예시는 `sample/`. 추가한 환경변수와 배포 방법은 `env.md`. 여러 주에 걸친 작업 계획과 Phase별 확인 기록은 별도 파일(`daily-core-e2e.md`).
