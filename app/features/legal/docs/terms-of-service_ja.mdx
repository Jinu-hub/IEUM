## 2. 定義
1. **当サービス**：AI を活用したエンジニアリングインサイトおよび自動レポート生成プラットフォーム。  
2. **ユーザー**：本規約に同意し、当サービスを利用する個人または組織の構成員。  
3. **ワークスペース**：ユーザーまたは組織が作成し、チームで利用する環境。  
4. **外部連携サービス**：OAuth 認証を通じて接続される GitHub、Slack 等の第三者サービス。  
5. **コンテンツ**：当サービス内で生成またはアップロードされるすべてのデータ、レポート、テキスト等。  
6. **有料サービス**：料金の支払いが必要な機能またはサービス。

## 4. アカウント登録およびアカウント管理

1. 当サービスは、以下の方法でアカウント登録およびログインをサポートします。
   - メールアドレスによる登録・ログイン  
   - Google アカウント認証  
   - GitHub アカウント認証  
   - Apple ID 認証  
   - 今後追加されるその他の OAuth 認証サービス  

2. ユーザーは、登録時に正確かつ最新の情報を提供する必要があります。

3. アカウント（メール登録の場合のパスワード管理を含む）はユーザー自身の責任で管理するものとします。  
   アカウントを第三者と共有したり、第三者のアカウントを無断で使用することは禁止されています。

4. OAuth 連携により作成されたアカウントは、各 OAuth 提供元が提供する認証情報に基づきログインが行われます。

5. 以下の場合、アカウントの作成または利用を制限することがあります。
   - 虚偽または不正確な情報が提供された場合  
   - 不正目的でアカウントが作成された場合  
   - サービスの安定性・セキュリティを脅かす行為があった場合
