# プライバシーポリシー (Privacy Policy)
_最終更新日: {{privacy_last_updated}}_

## 1. はじめに

NexLetter（以下、「当サービス」）へようこそ。  
NexLetter は、GitHub や Slack などの外部サービスから開発活動データを収集・分析し、AI を用いて自動的にレポートやインサイトを生成するエンジニアリング向けプラットフォームです。

本プライバシーポリシーは、当サービス利用時に収集される情報、その利用方法、保存方法、および保護体制について説明するものです。

当サービスを利用することで、本ポリシーに同意したものとみなします。

---

## 2. 収集する情報

### 2.1. アカウント情報
アカウント作成またはワークスペース参加時に以下の情報を収集する場合があります。
- 氏名または表示名  
- メールアドレス  
- プロフィール画像（OAuth 提供者による）  
- OAuth 認証情報（例：Slack、GitHub）

パスワードは保存しません。認証はすべて OAuth により行われます。

---

### 2.2. ワークスペースおよび組織情報
以下の情報が収集される場合があります。
- ワークスペース名・設定  
- 組織構造・メンバー情報  
- 権限・ロール情報  
- 外部サービス連携の設定データ  

---

### 2.3. 外部サービス連携データ（GitHub、Slack 等）
ユーザーが OAuth により連携を許可した場合、以下の情報が収集されます。

**GitHub**
- リポジトリのメタデータ（名称、URL、公開/非公開など）  
- コミット、プルリクエスト、Issue、コメントなどの活動データ  

**Slack**
- チャンネルのメタデータ（名称、メンバー一覧 — 許可範囲内）  
- メッセージおよびスレッド内容 — 許可した OAuth スコープに限定  

**共通**
- 連携サービスのイベントログ  
- レポート生成に必要な活動データ全般  

> 明示的な許可がない限り、非公開リポジトリやプライベートチャンネルにはアクセスしません。

---

### 2.4. 自動的に収集される情報
サービス利用時に以下の情報が自動的に収集されます。
- 端末情報  
- ブラウザ / OS の種類  
- IP アドレス  
- アクセスログ、利用ログ  
- 利用行動パターン

## 3. 収集した情報の利用目的

### 3.1. 自動レポートおよびインサイト生成
- GitHub / Slack の活動要約  
- KPI や主要トピックの抽出  
- 週次 / 月次レポート生成  
- ユーザーごとのインサイト提供  

### 3.2. サービス機能の提供
- ワークスペース管理  
- 外部サービス連携の同期  
- ダッシュボードおよび分析機能  
- メール・Slack 通知  

### 3.3. サービス改善
- 利用状況分析  
- 機能改善およびバグ修正  
- AI 要約精度の向上  

AIで生成された出力物は理解を助けることを目的としており、不正確な内容が含まれる可能性があります。

### 3.4. セキュリティおよび法令遵守
- 不正アクセス防止  
- ログ・監査体制  
- 法令対応  

> 当サービスはユーザーデータを第三者へ販売しません。

## 4. データ処理および保存

### 4.1. データ処理
収集されたデータは以下の目的で処理されます。
- 活動データの取り込み  
- AI による要約・分析  
- トピック分類・ハイライト抽出  
- レポートおよびダッシュボード生成  

NexLetterは大規模言語モデル（LLM）を含む自動化システムを使用して、収集された活動データを基に要約、ハイライト、分析的インサイトを生成します。

AIで生成されたコンテンツは情報提供目的でのみ提供され、不正確な内容が含まれる可能性があります。  
ユーザーはコンテンツに基づいて決定を下す前に、出力結果を確認することを推奨します。

Slack、GitHub、その他の統合データは**AIモデルの学習には使用されません**。

一部処理は外部 AI サービス（OpenAI など）により行われる場合があります。  
これらの提供会社は厳格なセキュリティ・プライバシー基準を満たす必要があります。

### 4.2. データ保存
データは暗号化されたデータベース（Supabase など）に安全に保存されます。  
秘密鍵・API キーは安全な Vault にて管理されます。

外部AIプロバイダーを使用して処理を行う場合、データは厳格な機密保持およびセキュリティ契約に従って取り扱われます。  
AIプロバイダーはNexLetterのための出力物生成目的でのみデータを処理し、リクエストの範囲を超えてデータを保持または再利用することはありません。

### 4.3. データの保持期間
データは以下の目的に必要な期間のみ保持されます。
- サービス提供  
- 法令遵守  
- 機能改善  

これはAIシステムで処理されたデータにも同様に適用されます。  
ユーザーはいつでも削除を依頼できます。

## 5. 情報の共有

以下の場合に限り情報を共有することがあります。

### 5.1. ユーザーが連携した外部サービスへの提供
- Slack ボットの応答  
- GitHub App による自動コメント・ステータス更新  

NexLetterは、ユーザーが明示的に設定しない限り、自動的にチャンネルに参加したり、メッセージを投稿したり、プライベートな会話にアクセスすることはありません。

### 5.2. ワークスペース内メンバーとの共有
権限設定に従い、レポート・インサイト・活動データが共有される場合があります。

### 5.3. サービス運営に必要な第三者提供
- インフラホスティング  
- メール送信サービス  
- AI 処理サービス  

これらの企業は NexLetter の運用目的以外ではデータを利用できません。

### 5.4. 法的要請
法令や手続きに基づく場合、情報が開示される可能性があります。
