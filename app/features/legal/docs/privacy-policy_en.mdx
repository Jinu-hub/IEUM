## 1. Introduction

Welcome to IEUM (“we”, “our”, “the Service”).  
IEUM is an AI-powered engineering insights platform that collects and analyzes development activities—such as GitHub actions, Slack conversations, and other authorized integrations—to automatically generate reports and insights for teams.

This Privacy Policy explains what information we collect, how we use it, how we store it, and how we protect it.

By using our Service, you agree to this Privacy Policy.

## 4. Data Processing & Storage

### 4.1. Data Processing
Collected data is processed for:
- Activity ingestion  
- AI-based summarization and analysis  
- Topic classification and highlight extraction  
- Generating dashboards and reports  

IEUM uses automated systems, including large language models (LLMs),
to generate summaries, highlights, and analytical insights based on collected activity data.

AI-generated content is provided for informational purposes only and may contain inaccuracies.
Users are encouraged to review outputs before making decisions based on the content.

Slack, GitHub, and other integration data are **not used to train AI models**.

### 4.2. Data Storage
Data is securely stored using encrypted databases (e.g., Supabase).  
Secrets and credentials are managed using secure vault systems.

When external AI providers are used for processing, data is handled in accordance
with strict confidentiality and security agreements.
AI providers process data only to generate outputs for IEUM
and do not retain or reuse the data beyond the scope of the request.

### 4.3. Data Retention
We retain information only for as long as necessary for:
- Providing the Service  
- Legal compliance  
- Improving product functionality  

This applies equally to data processed by AI systems.
Users may request deletion at any time.

### 4.4. Processing Limitations & System Constraints

To ensure system stability, performance, and fair usage, IEUM applies technical safeguards when processing integration data.

This includes:
- Limiting analysis to a defined time window (e.g., weekly activity)
- Excluding files, images, and external attachments from analysis
- Applying automated summarization when message volume is excessive
- Processing data within technical constraints of third-party APIs

In cases where data volume exceeds system thresholds, portions of the data may be summarized or excluded to maintain processing stability.

These measures are implemented to protect system performance and ensure reliable service delivery.
